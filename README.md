## 他プロジェクトで使うときの最短経路

1. `docs/jev-usage-guide.md` §5「基本の形」の JS 例をコピーし、`state` と `questions` を差し替える。
2. 日本から呼ぶなら「注意点」の 6 つのコツ（質問をまとめる・並列・接続再利用 など）を先に読む。
3. 閾値やフォールバックの設計は付録「実装時の落とし穴」に従う。
